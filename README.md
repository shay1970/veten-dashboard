# דשבורד מנויים — ותן חלקנו

## קבצים בפרויקט
```
index.html   ← הדשבורד (לא נוגעים בו)
data.json    ← הנתונים בלבד (כאן מעדכנים כל יום)
```

## עדכון נתונים כל יום
1. פתח את הדשבורד ב-GitHub Pages
2. לחץ **＋ הוסף יום** והזן את הנתונים
3. לחץ **⬇ ייצא data.json** — הקובץ יורד
4. החלף את `data.json` בתיקייה
5. הרץ: `git add data.json && git commit -m "נתוני היום" && git push`
